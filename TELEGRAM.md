# Публикация «Моего тренера» в Telegram

## Что уже готово

`index.html` — статическое веб-приложение. Оно подключает официальный Telegram Web Apps SDK и подходит для открытия внутри Telegram после публикации на HTTPS-адресе. Отдельный сервер и токен бота для простого запуска Mini App не нужны.

## 1. Опубликуйте сайт через GitHub Pages

1. Создайте на GitHub новый репозиторий, например `my-trainer`.
2. Загрузите **содержимое этой папки** в корень репозитория: `index.html`, `data/`, `source/`, `skills/`, `README.md` и этот файл. Не загружайте токены, пароли или другие секреты.
3. В репозитории откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/(root)`, затем нажмите **Save**.
5. Дождитесь адреса вида `https://ВАШ-ЛОГИН.github.io/my-trainer/`. Откройте его и убедитесь, что приложение загрузилось. Для GitHub Pages можно включить **Enforce HTTPS** в настройках Pages.

## 2. Привяжите адрес к боту

В Telegram откройте `@BotFather`, выберите своего бота и задайте **Menu Button / Web App**. В качестве URL вставьте опубликованный HTTPS-адрес. Название кнопки можно выбрать, например, «Мой тренер».

Другой путь: в `@BotFather` используйте `/setmenubutton`, выберите бота, задайте текст кнопки и HTTPS URL.

Затем откройте чат с ботом и нажмите кнопку меню. Mini App должен загрузиться внутри Telegram.

## Данные и будущие изменения

- Изменения в коде можно продолжать после публикации: загрузите новую версию файлов в ту же ветку GitHub, и Pages обновит сайт.
- Сейчас планы и дневник хранятся только в локальном хранилище браузера на устройстве. GitHub Pages не синхронизирует их между устройствами.
- Для ИИ-тренера, напоминаний от бота и общей базы нужна серверная часть. Токены и ключи API нельзя помещать в `index.html` или публичный GitHub-репозиторий.
- Токен бота, уже отправленный в переписку, нужно отозвать через `@BotFather` командой `/revoke` и выпустить новый. Для публикации Mini App токен не нужен.
